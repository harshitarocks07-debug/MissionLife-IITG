# MissionLiFE-Impact

## Overview
MissionLiFE-Impact is a sustainability platform that encourages citizens to adopt eco-friendly habits, track their carbon footprint, reduce energy consumption, and explore renewable energy alternatives.

## Tech Stack

- **Frontend:** React.js
- **Backend:** Python, FastAPI
- **Database:** PostgreSQL
- **Data Visualization:** Chart.js / Recharts
- **Version Control:** Git and GitHub

## Project Workflow

1. **User Registration:** Users access the platform and provide relevant lifestyle and energy-consumption information.
2. **Footprint Calculation:** The backend processes user inputs to estimate their carbon footprint.
3. **Personalised Recommendations:** The system provides actionable suggestions for reducing energy consumption and environmental impact.
4. **Green Challenges:** Users participate in sustainability activities and track their completion.
5. **Gamification:** Points, achievements, and leaderboards encourage consistent participation.
6. **Solar Insights:** Users can explore rooftop solar feasibility and estimated savings based on relevant inputs.
7. **Progress Tracking:** The dashboard visualises footprint trends, completed challenges, and sustainability progress.

## Core Modules

- **Carbon Footprint Tracker:** Estimates and monitors individual environmental impact.
- **Energy Recommendation Engine:** Suggests practical energy-saving actions.
- **Green Challenge System:** Tracks daily sustainability activities.
- **Gamification Module:** Manages points, achievements, and leaderboards.
- **Solar Feasibility Module:** Provides preliminary rooftop solar estimates.
- **Analytics Dashboard:** Displays user progress and environmental insights.

## Expected Impact

MissionLiFE-Impact aims to bridge the gap between environmental awareness and everyday action by making sustainable behaviour measurable, engaging, and accessible.
